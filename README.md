# hotel-booking-analysis-powerbi
Power BI dashboard analyzing hotel booking data for Velora Hotel — covering revenue, cancellations, occupancy, loyalty segments, and booking channel performance.

## Dashboard Preview
https://github.com/VishalYoMama/hotel-booking-analysis-powerbi/blob/main/power-bi-dashboard.png

## Key Metrics
| Metric | Value |
|--------|-------|
| Total Bookings | 5K |
| Total Revenue | $1M |
| Cancellation Rate | 28.7% |
| Total Room Nights | 9K |
| Avg. Room Rate | $147.8 |

## Analysis Covers
- **Daily stay trends** – peak and off-peak booking patterns
- **Weekday vs Weekend** – which days see the most stays
- **Guest loyalty breakdown** – Non-member, Iconic, Elite, Premier, Essential, Preferred, Select
- **Booking lead time** – how far in advance guests book
- **Booking channels** – App, At the property, Connected, GDS, Phone, Velora website
- **Loyalty % and one-night vs multi-night stays**

## Pages in the Report
- Website Overview
- Room Report
- Occupancy
- F&B Report

## Tools Used
- Power BI Desktop
- DAX measures
- Interactive slicers (date range filter)
